Frequently Asked Questions

Quick answers for the Media AE Cockpit project.

What is this project for?

Media AE Cockpit is a lightweight workspace to centralize common account executive tasks and project references.

How do I view this FAQ locally?

Run a local static server from the repository root and open http://localhost:8000/faq.html in your browser.
